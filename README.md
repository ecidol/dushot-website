# Dushot website

English marketing website for Dushot, served as static HTML through GitHub Pages.

## Site content

The page describes the developer-confirmed product direction: simultaneous portrait and landscape photos and videos on iPhone, still photos during recording, separate framing controls, a movable and resizable landscape preview, direct saving to Photos, and language following system settings.

The geometric hero is explicitly labeled as a **framing illustration**, not an app screenshot. There are no product screenshots, customer claims, ratings, prices, device specifications, or invented App Store links.

The site does not independently verify the app binary, device compatibility, or real-device capture results. Keep copy aligned with the actual released version.

## Maintenance

Edit `index.html` to change copy, styling, or links. All styling is inline. There are no JavaScript dependencies, tracking scripts, external fonts, photos, forms, or build steps.

Keep the empty `.nojekyll` file in the repository root. GitHub Pages can publish from the `main` branch and the `/(root)` directory.

Check the published page after each change, including its small-screen layout, anchor navigation, email links, and links to the support center. Keep private app code, credentials, and user reports out of this public website repository.

Add an App Store download link only after the developer provides or confirms the real listing. Do not imply a store release, availability date, subscription, or price without confirmation.

App Store Connect has separate **Marketing URL**, **Support URL**, and **Privacy Policy URL** fields. This marketing page does not replace a privacy policy.

Apple reference: https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information
